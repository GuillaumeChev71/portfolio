## ArbitreApi
| Method | Endpoint | Description |
|---------|-----------|-------------|
| GET | `/api/arbitres` | Retrieves the collection of Arbitre resources. |
| GET | `/api/arbitres/{inNo}` | Retrieves a single Arbitre resource. |

## EquipeApi
| Method | Endpoint | Description |
|---------|-----------|-------------|
| GET | `/api/clubs/{clNo}/equipes` | Retrieves the teams of a club. |
| GET | `/api/clubs/{clNo}/equipes/{equipes}/engagements` | Retrieves team engagements. |
| GET | `/api/clubs/{clNo}/equipes/{equipes}/matchs` | Retrieves matches of a team. |

## MatchEntityApi
| Method | Endpoint | Description |
|---------|-----------|-------------|
| GET | `/api/match_entities` | Retrieves all match entities. |
| GET | `/api/match_entities/{maNo}` | Retrieves a specific match entity. |
| GET | `/api/clubs/{clNo}/matchs` | Retrieves matches of a club. |
| GET | `/api/clubs/{clNo}/calendrier` | Retrieves club calendar. |
| GET | `/api/clubs/{clNo}/resultat` | Retrieves club results. |
| GET | `/api/compets/{cpNo}/phases/{phNo}/poules/{gpNo}/matchs` | Retrieves matches of a competition. |
| GET | `/api/compets/{cpNo}/phases/{phNo}/poules/{gpNo}/resultat` | Retrieves results of a competition. |
| GET | `/api/compets/{cpNo}/phases/{phNo}/poules/{gpNo}/calendrier` | Retrieves competition calendar. |
