### Client Python `api-client-fff`

Un client Python généré automatiquement via Swagger est disponible sur PyPI : [api-client-fff](https://pypi.org/project/api-client-fff/) (v0.1.5, licence LGPLv3+, auteur Thibault Falque). Il requiert Python ≥ 3.10 et aucune authentification n'est nécessaire pour les endpoints.

Installation :

```bash
pip install api-client-fff
```

Exemple d'utilisation :

```python
import apifff
from apifff.rest import ApiException
from pprint import pprint

# Collection d'arbitres (paginée)
api = apifff.ArbitreApi(apifff.ApiClient(apifff.Configuration()))
try:
    pprint(api.get_arbitre_collection(page=1))
except ApiException as e:
    print("Exception: %s" % e)

# Fiche arbitre par identifiant
try:
    pprint(api.get_arbitre_item(in_no="..."))
except ApiException as e:
    print("Exception: %s" % e)
```

Tous les endpoints listés ci-dessus exposent une classe `*Api` correspondante (par ex. `ClubApi`, `MatchEntityApi`, `TerrainApi`) avec des méthodes `get_*_collection` / `get_*_item`.
